# Project initialising instructions

1. Ensure you have Python installed (open CMD and run `python --version` or `python3 --version`) 

2. If Python is not installed install Python 3.>11 (DIY, just ChatGPT it out). Python 3.13 is fine

3. Ensure Python installed correctly by running `python --version` or `python3 --version` succesfully. Remember wether it is *python* or *python3* for further instructions. In this tutorial *python* will be used by default, substitute as needed.
 
4. Go to `CNN_scrapper` folder. From the current CMD, use `cd` to achieve this 

5. Once inside, run `python -m venv venv`

6. Then run `venv\Scripts\activate`

7. You should see **(venv)** appear to the left of your console prompt. If you don't get here, ask the teacher "How to activate a venv"

8. Once inside the venv, run `pip install -r requirements.txt`. If pip is not installed, ask the teacher "How to install pip on a venv"

9. After this, run `python app.py`

If everything goes well, the back is now running. This console must remain open for the backend to work.

You can now run `npm run dev` on the main project folder from another terminal to test the front-end
